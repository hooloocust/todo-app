# 📝 Todo App

A simple single-user Todo desktop application built with Python, Tkinter, and Peewee ORM.

## Quick Start

```bash
git clone https://github.com/hooloocust/todo-app.git
cd todo-app
uv sync
uv run todo
```

## Features

- ➕ Add new todos with title and description
- ✏️ Edit existing todos
- 🗑️ Delete todos
- ✅ Toggle completion status
- 📋 View all todos in a scrollable table
- 📝 View full description when selecting a todo

## What's in the Box

- **Python** — main language
- **Tkinter** — desktop UI
- **Peewee ORM** — database layer (SQLite3)
- **uv** — fast dependency management
